📦 Kit PWA — Lecture de notes

Cette page prépare les 4 fichiers compagnons du quiz. Dépose-les dans le même dossier que le fichier du quiz renommé index.html, puis pousse le tout sur GitHub Pages.

💡 Si les boutons de téléchargement ne font rien dans l'aperçu du canvas, télécharge d'abord cette page (export du canvas), ouvre-la dans Safari ou Chrome, puis clique sur les boutons. Tu peux aussi copier les contenus ci-dessous à la main.

📁 Les 5 fichiers du dépôt GitHub

  • index.html Le canvas « Lecture de notes » exporté et renommé
  • manifest.webmanifest → bouton ci-dessous
  • sw.js → bouton ci-dessous (cache hors-ligne)
  • icon-180.png, icon-192.png, icon-512.png → boutons ci-dessous (icône iOS + Android)

🗂 manifest.webmanifest

Déclare le nom, les couleurs et les icônes de l'application installable.

Mise en cache du site pour un fonctionnement hors-ligne une fois l'app installée.

    

    

      
      
    

  


  

    
🎨 Icônes PNG (180, 192, 512)

    

      
      L'icône icon-180.png est celle utilisée par iOS pour l'écran d'accueil. Les tailles 192 et 512 servent à l'installation sur Android/Chrome.
